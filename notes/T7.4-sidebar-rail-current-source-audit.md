# T7.4：Sidebar Rail 当前来源审计

**官方基线：** `deepseek-ai/deepseek-harness@528c682e061696f5a160f363f236ecbf53cbd006`（`dsh-v0.1.1-rc.1`）。本审计限定 T7.
4 的 sidebar wide/rail 状态、region 挂载和 motion 语义；它不将上游 WebUI 测试替代为原生 AppKit 验收。


## 锁定官方契约

官方 `SidebarRoot` 保持 workspace region 在 collapse 过程中的 composition ownership；
wide flag 由 sidebar shell 传给 region，region 发出的 expand request 仅在 collapsed 状态下改变 layout。
冷启动的 collapsed rail 没有 live collapse crossfade class；
动画只属于真实 wide→rail 转场。
[1] CSS 进一步规定 rail 以 56px column、36px control box、slide/crossfade 和 `prefers-reduced-motion` 下禁用 transition/animation 的方式运行。[2]

| 行为 | 当前原生映射 | 未完成证据 |
|---|---|---|
| 宽/窄阈值与 rail | `NativeSidebarLayoutState` 与 `OfficialColumnLayout` | 1023px light/dark paired captures。 |
| rail 请求展开 | `NativeShellPresentation` 的临时 `narrowExpanded` 路径 | 真实 AppKit focus 与交互记录。 |
| region/search 在 rail 转换中保留状态 | `WorkspaceBrowserView` 的 local search-on-expand state | 当前 SHA runtime XCTest 与 AX tree。 |
| Reduce Motion | 原生 navigation animation 返回静态分支 | macOS 系统偏好实际运行态证据。 |
