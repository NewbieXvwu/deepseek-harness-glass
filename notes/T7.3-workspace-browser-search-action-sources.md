# T7.3：Workspace Browser 搜索与行操作当前来源审计

**官方基线：** `deepseek-ai/deepseek-harness@528c682e061696f5a160f363f236ecbf53cbd006`（`dsh-v0.1.1-rc.1`）。本记录只说明原生侧已映射的行为契约与仍待完成的视觉/运行态证据；不把本地或历史 WebUI 结果当作当前 macOS 验收。

## 官方行为契约

锁定官方 `WorkspaceBrowser` 将 wide search、rail search、结果树与 workspace/session 行操作放在同一 sidebar 区域。Rail search 先将 `searchExpanded` 与 `searchOnExpand` 置位，再请求 shell 展开；wide input 在 300ms column slide 后取得焦点，避免聚焦触发同步 layout 干扰动画。[1] 搜索 query 先移除 NUL、限制为 500 个 UTF-16 code units 且不截断 surrogate pair；非空 query 经 250ms debounce 调用可取消的 Host `session.search`，本地 metadata matches 与当前 Host result page 合并，过期或取消请求不得发布结果。[1]

| 官方行为 | 原生映射 | 当前验证边界 |
|---|---|---|
| rail search 展开后 300ms 聚焦 | `NativeWorkspaceBrowserSearchOnExpand` + task cancellation | `NativeWorkspaceStoreTests` 锁定 collapse/focus/settle/dismiss 纯状态；仍待 macOS 键盘焦点工件。 |
| Escape 或 clear 关闭并清空 search | `dismissSearch()` 同时清 query、清 focus、撤销 arm | 保持 SwiftUI `TextField` 的原生 key handling；仍待 runtime AX/interaction 证据。 |
| Host-authoritative content search | `NativeWorkspaceStore.remoteSearch` 与 Shell typed facade | native 只合并完整 Host snapshot 的可见 metadata 与当前 Host results，不创建私有内容索引。 |
| workspace/session rename/delete/archive | browser-owned sheet 及 Host typed callback | modal 可跨 row unmount；删除只在 Host refresh 移除 ID 后关闭。 |
| row reorder | `NativeWorkspaceBrowserOrdering` 和 typed move callbacks | local order 只是浏览器视图状态；Host refresh 是 durable membership/order 的唯一 authority。 |

官方 `WorkspaceBrowser` 行为测试已于 2026-08-22 以 Node `24.19.0` 在锁定工作树运行：

该命令的 1 个测试文件、44 项测试全部通过，覆盖 rail-open search、outside-click 保留非空 query、remote search cancellation、Host error、result bound、workspace/session rename、delete confirmation、archive、reorder 及 search 下隐藏 drag affordance。[2] 此结果仅验证上游基线自身的当前契约，不能替代原生配对截图、真实 AppKit focus、Host runtime 或 macOS-26 XCTest。

## 原生边界与未完成证据

原生 `WorkspaceBrowserView` 已采用同一 300ms rail focus 延迟，使用 `NativeWorkspaceStore.sanitizeSearchQuery` 保持 wire-safe input，并将 query 变化交给 Shell-owned typed search action。其 search results 的 loading、failed、no match 与 has-more 文案均来自 `OfficialUISpec`。workspace/session rename、archive 与 delete 均不在 Browser snapshot 上乐观伪造 Host authority。

T7.3 仍保持未完成。必须获得当前 SHA 的官方/原生 search、workspace rename、session rename 与 workspace delete 的 light/dark 同状态截图、ARIA/geometry、差异报告、人工分类及 macOS-26 权威工件后，才可关闭该任务。
