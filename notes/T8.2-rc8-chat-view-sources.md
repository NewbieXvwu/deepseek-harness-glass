## 当前原生边界

当前 `NativeSessionStore` 已以 `ConversationNodeReducer` 将 Host history/mux event materialize 为 `chatNodes`，并在 resident session state 中保存/恢复 reducer raw window 与 keyed target snapshot；`NativeTranscriptScrollView` 消费其 stable key。该基础不得被 T8.2 后续 UI 收敛回退为 transcript text 的临时拼接。

T8.2 仍未完成。原生尚需继续按 current source 补齐 streaming/final same-node row behavior、scroll anchoring/bottom-follow、基础 turn chrome 以及 current SHA macOS visual/AX/interaction evidence。context、reasoning、tools、feedback、branch、Markdown/code/link safety 和 composer/queue 控制仍按原任务边界归属 T6.6、T8.3–T8.7 与 T9，不得用伪摘要填充。
