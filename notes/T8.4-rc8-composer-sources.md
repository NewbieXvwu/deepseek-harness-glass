## 现有原生 authority 证据

`NativeSessionStoreTests.testCancelIntentUsesTypedFacadeOnlyForHostRunningTurn` 以拒绝型 `NativeSessionAPI` recorder replay `turn/start`，断言 idle composer 不制造 cancel RPC，只有 Host-projected running 状态才经 typed facade 发送 cancel；carrier 拒绝或返回不乐观把 `isRunning` 置为 false。

`NativeSessionStoreTests.testAcceptedPromptClearsDraftOnlyAfterTypedHostFacadeAcceptance` 以 `SessionPromptResponse(accepted: true)` 验证 draft 在调用后、Host acceptance 前仍保留，并仅在 acceptance 后清空。该正例与拒绝后保留 draft 的回归共同保持官方 retry posture；durable user row 仍须等待 SSE/Host event，不能由 UI optimistic append。
