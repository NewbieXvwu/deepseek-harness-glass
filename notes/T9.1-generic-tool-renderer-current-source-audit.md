# T9.1：Generic Tool Renderer 当前来源审计

**官方基线：** `deepseek-ai/deepseek-harness@528c682e061696f5a160f363f236ecbf53cbd006`（`dsh-v0.1.1-rc.1`）。
本记录约束原生 generic tool fallback 的数据保全、状态、展开和 keyed node ownership；
不以官方侧测试取代当前 SHA 的 AppKit runtime、AX 或 visual 验收。

## 锁定官方契约

官方 `ChatNodeSeat` 按稳定 `nodeKey` 单独订阅 node，并以同一个 node key 为 DOM flow/anchor identity；
未知 chat node 通过带 localized type label 的 `JsonBlock` 保留 payload，而不是删掉或伪装成已知消息。
Tool 树再按 call ID 建立递归但原子 keyed branch，tool-specific registration 无法处理的名称会进入 `GenericToolCard`。[1] [2]

`GenericToolCard` 以 `toolRowModel` 派生可见 variant、title、summary、arguments body、output、error summary 与 file path，但不将 unknown tool 静默丢弃。
它将 terminal/card-specific presentation 作为可选扩展：terminal description 或 search title 可以替换上方 summary；
single-file tool 不重复暴露 arguments body，但仍可在展开后展示关联 card；terminal nonzero exit 则把 row 置为 error state。[1]

| 契约 | 原生现状 | 未完成边界 |
|---|---|---|
| stable tool identity 与 Chat 分流 | transcript 将 typed `ToolInvocation` 与 chat nodes 合并，
并以 `tool-<id>` 为稳定身份 | 仍需 current-SHA macOS streaming/prepend/scroll 证据。
|
| raw arguments / output 保全 | `NativeToolRow` 保留完整 raw arguments/output；`NativeToolDetailsBody` 同时展示两者，
output 不再覆盖/吞掉 input | 需未知工具完整 fixture、超长 payload 性能与 copy AX。
|
| generic fallback 状态和折叠 | `NativeToolRowModel` 从 typed invocation 派生摘要、路径与 state；
details fallback 使用 raw region | 需对齐 official tool/card-specific expansion、loading/cancelled 与 visual geometry。
|
| tool-specialized renderer ownership | T8 chat 仅消费 typed tool row，T9 承担 tool card/detail semantics | T9.2/T9.
5 不得把 raw event 或未验证 product wording 带回 chat renderer。
|

2026-08-22 已用 Node `24.19.0` 运行锁定官方 `packages/client/ui-tool/tests/assembly-surfaces.client.spec.tsx`；1 个文件、2 项测试全部通过。
测试确认 keyed bash row 与未注册 `fx-bash` generic fallback 都通过整行展开到 terminal card，且 todo/write assembly 不出现重复 outlet。
它验证上游当前 generic fallback 与 keyed registration 的行为来源，**不替代**本项目 native tool renderer 的 XCTest、macOS-26 runtime、paired PNG/ARIA 或人工差异分类。
