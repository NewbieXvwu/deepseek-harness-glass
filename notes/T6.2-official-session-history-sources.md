# T6.2：SessionHistoryPager 官方来源、行为映射与证据边界

**锁定官方版本：** `deepseek-ai/deepseek-harness@99f6f02fecdb7dff40c3fbc9470f5907c29f74ca`

**原生测试：** `glass/Tests/Core/SessionHistoryPagerTests.swift`

## 范围

`SessionHistoryPager` 是 Core 层的 Host-authoritative **原始事件窗口**。它不解析业务节点、不渲染 SwiftUI、也不拥有任何 AppKit/WebKit 表面；
其输出仅是连续的 `SessionHistoryEntryDTO` 区间、对应 projection baseline、`hasMore` 与显式加载/错误状态。
`ConversationNodeReducer` 和后续 Chat renderer 消费该窗口，因此本任务的视觉证据采用**Core-only 边界审阅**，而不伪造一个尚未由 T8.2 完成的分页界面。

> 这不是对分页视觉的豁免。待 T8.2 `ChatView` 呈现历史分页后，相关用户可见状态必须以相同官方 fixture、视口、DPR、locale 和颜色模式生成官方/原生配对，并纳入对应 UI TODO 的 `enforce` 验收。

## 已覆盖的失败路径

当前 Swift 测试覆盖 tail/older 的 50-message 约束、连续区间、compaction 边界、空 `hasMore` 守卫、重复/倒序 tail、重复/乱序 older page、tail retry、live duplicate/gap 以及
older-page in-flight coalescing。



异常被收敛为 `DSHTransportError` 并显式投影为 `TailState.failed` 或 `OlderState.failed`；既有良好窗口不会在完整性失败时被覆写。
