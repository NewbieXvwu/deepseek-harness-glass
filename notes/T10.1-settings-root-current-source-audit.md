## rc.2 锁定契约

官方 `SettingsRoot` 自行持有 `open` 与 active section ID：`close`同时关闭并清除active，`openSection`同时设置section并打开panel。以有序section ledger生成nav rows；用户无显式选择地打开或当前entry注销时，panel回退到first row；ledger为空时仅渲染空content column，不伪造产品section。[1]

> SettingsPanel的dialog accessibility name来自header seat ID；shell-owned close button使用`settings.close` seat的可见性隐藏label。打开时焦点直接落到close button，mask、header close和document Escape均关闭panel。[1]

| 契约 | 当前原生映射 | 仍待闭环 |
|---|---|---|
| 官方close文案 | Native toolbar close现读取`ui-settings-general.close`，不再错误借用`ui-settings-plugins.collapse`。 | current-SHA AX验证可访问名称。 |
| 初始focus | `@FocusState`在NativeSettingsRoot appear时聚焦shell-owned close Button；父级负责AppKit window创建。 | native window首次打开/重新激活的runtime focus工件。 |
| close/Escape | `NativeShellController`的独立settings `NSWindow`通过toolbar close及`windowWillClose`回写`settingsPresented=false`；AppKit closable window承担Escape/cancel标准操作。 | current-SHA close/Escape集成测试。 |
| official content boundary | 移除了本地`Plugin profile`、`Use an isolated plugin profile`及DSH_HOME说明，它们不是rc.2 SettingsRoot/locale来源。 | 需以official ledger替代现有静态4-section导航，或明确各builtin section登记证据。 |
| active fallback/empty ledger | 原生目前静态`SectionID.allCases`而非动态ledger。 | unregister→first、empty column与onboarding ownership尚未对齐。 |
