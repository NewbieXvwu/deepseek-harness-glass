## Host authority 与 mutation 路径

`GoalBar` 的可见 value 来自 `useProjection('goal')`，其 injected face 只有 `onEdit/onPause/onResume/onClear`。[1] 原生侧遵循相同拆分：`SessionGoalProjectionReader` 读取 whole projection；`NativeGoalAPI` 只包装已有 `CommandsAPI.edit/pause/resume/clear`。所有请求携带 active session 的 `id + revision` compare-and-set ref。返回的 reference **不得写回** projection；后续 `session/projection` 才是状态变更权威。

成功 clear 是唯一短暂 presentation 例外：官方测试明确要求 projection 尚未追上时先隐藏已提交 clear 的同一 goal。[2] 因此 native store 只公开 `locallyClearedGoalID`；renderer 根据 current goal identity 决定是否隐藏。它没有创建 local tombstone，也不影响任何 Host projection reader。

## 当前平台修复

macOS-26 run `32389790574` 显示 Goal pause/resume/clear 的 XCTest request comparison 需要 `GoalReferenceRequest: Equatable`，其嵌套 `GoalReferenceDTO` 也必须可比较。两者均为纯 Codable value DTO，已补合成 `Equatable`；此修复不改变 `goal.*` RPC payload、CAS reference 或 Host-authoritative projection。

## 待闭环证据

新增 Goal dock 尚未获得独立的 official Playwright real-projection capture、light/dark paired PNG、ARIA/keyboard interaction snapshot、差异分类与当前 SHA 的 macOS-26 XCTest。当前 Linux 环境因共享 `GlassSpec` target 直接依赖 AppKit/SwiftUI，不能构建 SwiftPM tests；仅执行语法、资源再生、规格/视觉/workflow/document gates，macOS CI 仍是类型和 GUI runtime 权威。
