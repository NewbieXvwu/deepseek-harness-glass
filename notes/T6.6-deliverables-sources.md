## 安全与 authority 边界

`NativeProducedFiles` 不访问本地文件系统，也不从 assistant Markdown 推断路径。它只接收 reducer location data，并调用已有 `openKnownProjectPath` Host seam；该 seam拒绝 URL/空白 token，按 active session cwd解析后才发送 typed `host.openPath`。目录动作的显示资格另由Shell中已验证loopback Host的`host.describe.canOpenPath`给出；不存在该权威事实时不会显示该动作。

## 待闭环证据

`loadSnapshotDeliverablesFixture()` 现以真实typed event chain装配与上游场景同序的十路径状态：`turn/start → tool/call(diff locations) → successful tool/result → closing assistant/message → turn/end`。`NativeSessionStoreTests.testSnapshotDeliverablesFixturePublishesReducerOwnedTurnPaths`锁定closing assistant关联的完整有序路径；`DSH_GLASS_SNAPSHOT_MODE=deliverables`、`verify-native-shell.sh`和macOS workflow均会以780×900生成并校验`deliverables-light.png`，并在fixture-only recorded `canOpenPath`事实下显示同状态folder action。

官方同状态mutation-tool capture现已归档为`visual-review/official-141eb6f/deliverables-light-official.{png,json}`及`deliverables-light-official-capture.md`：它由RC8原始十write场景在780×900、en-US/light下真实产生，AX锁定两个basename chip、`+ 8 files`和`Show in folder`。该场景已登记到interaction scene目录、visual policy、baseline cache gate和native comparison入口。仍缺native当前SHA macOS截图/AX树、official/native paired PNG与diff/report、人工差异分类。深色场景也尚未定义官方同状态证据。因此 T6.6 保持未勾选。
