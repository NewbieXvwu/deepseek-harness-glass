## 安全与 authority 边界

`NativeProducedFiles` 不访问本地文件系统，也不从 assistant Markdown 推断路径。它只接收 reducer location data，并调用已有 `openKnownProjectPath` Host seam；该 seam拒绝 URL/空白 token，按 active session cwd解析后才发送 typed `host.openPath`。
