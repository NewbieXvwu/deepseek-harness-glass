# T6.4 ConversationNode 官方规格来源

锁定参考版本：`deepseek-ai/deepseek-harness@99f6f02fecdb7dff40c3fbc9470f5907c29f74ca`。

| 官方源文件 | 采用的约束 |
| --- | --- |
| `packages/client/runtime/src/client/contract/conversation.ts` | `ConversationNodeDefinition` 是事件到节点状态机；定义 `match`、`start`、`update`、可选 `publication`、`buildLocationData`、`buildViewNode`。`ConversationMatch` 保留 raw event、optional wire view、role 与 engine-owned location。`ChatConversationViewNode` 必须显式持有 `anchorSeq`、`location`、`visibility` 与固定 `target: 'chat'`。`conversationContextKey(kind,id)` 是 `"${kind.length}:${kind}${id}"`。 |
| `packages/client/runtime/src/client/sessions/conversation-assembler.ts` | Session-owned assembler 独占 event 解析与 State 采纳；start 唯一、update 只能在start之后按严格seq追加。`publication` 使用 none < animation-frame < immediate 的最大值。`buildViewNode` 输出必须复用context key并匹配definition target；隐藏应作为node visibility而非不稳定删除。 |
| `packages/client/runtime/src/client/sessions/conversation-location-index.ts` | match location 由engine维护的session/turn/step索引解析，业务definition只读取location，不自行推断时间线。 |

Swift实现文件：`glass/Sources/Core/Session/ConversationNode.swift`。该文件保持Core-only，不导入SwiftUI/AppKit；SwiftUI后续只消费已materialize的 `ConversationViewNode`。
