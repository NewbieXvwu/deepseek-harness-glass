## 官方 details shell 契约

官方 `DetailsPanel` 将 selection 的 `callId` 映射到窗口内 frozen material。无 selection 显示 `details.empty`；有 selection 但 material 不在当前 window 显示 `details.notInWindow`；material 存在时 header 优先显示 material name，随后才是 selected tool name/default details title。Input section 在 `argsRaw !== null` 时出现，Output section 对每个 material 始终出现，并以 selected `callId` 为 React key，使 terminal card 的 copy/expand 内部状态不会携带到下一条选择。[1]

| 官方状态 | Header | Body | 本轮原生约束 |
|---|---|---|---|
| 无 selection | `details.title` | `details.empty` | 不虚构 tool title；保留 current `detailsEmpty`。 |
| 有 selection、material 缺失 | selection tool name 或 details title | `details.notInWindow` | 不得错误显示空 selection guidance。 |
| material 存在 | material name | Input JSON + Output slot | `ToolInvocation.arguments` 与 `output` 必须同时保留，且 title 使用 Host name。 |
| running material | material name | Input JSON + Output `details.running` | 不得将 running 误报为空 output。 |
| settled unknown/malformed card | material name | Input JSON + raw flattened result | 不得以 name heuristic 进入专用 card。 |

`ToolDetails` 的 Output slot 先尝试 terminal → read → diff → search → web；所有未匹配、未知或无法验证的卡保留 settled `resultText` preformatted fallback，running non-terminal 显示 official details-running。[2] `resultText` 逐块 flatten 和 empty structured-error 语义由 T9.2 第四轮负责；该通用结果已进入 native `ToolInvocation.output`。

## 本轮 native shell 收敛（2026-08-22）

`NativeDetailsView` 现仅在已解析 selected invocation 时使用其 Host tool name 作为 header；缺失 material 时仍保留官方 Details title。`NativeToolDetailsBody` 新增 selection identity 输入，区分 no-selection 的 `details.empty` 与 selected-but-evicted 的 `details.notInWindow`；material 存在时使用官方 runtime locale catalog 的 `details.input`/`details.output`，始终显示 arguments 和 output section，并把 running placeholder 安置在 Output section。它继续呈现 raw generic fallback，尚未宣称实现 terminal/read/diff/search/web 专用 details card。

`NativeAccessibilityRuntimeTests.testToolDetailsExportsOfficialSectionsAndSelectionEmptyStates` 已为 material、not-in-window 和 empty 三种状态注册 macOS AX regression seam。该测试与 current-SHA native-ui 工作流是权威路径；本机 Linux 仅执行 source parse，不能替代 AppKit 运行时、focus/close、state persistence、paired visual 或 AX 证据。

## 未完成边界

本轮没有实现 `ToolDetails` 的 terminal → read → diff → search → web typed selector，也没有为 terminal details 安装 full-height card、为 read/diff/search/web 添加 renderer，或关闭 close/reopen、窄窗口自动关闭时的 selection/subtree persistence 视觉与 AX 证据。因此 **T9.6 保持未勾选**。

## Terminal details Output 增量（2026-08-22）

`NativeToolDetailsBody` 现复用已审计的 `NativeTerminalCardPresentation`：只有 running call 的 `callView.card == 'terminal'` 或 settled result 的 `resultView.card == 'terminal'` 进入 `NativeTerminalToolCardBody`，故 running terminal 不再被 generic `details.running` 覆盖；terminal call 后 generic result、未知 card、malformed card 与 running non-terminal 仍走原 generic path。Input section仍由 raw arguments 独立保留，符合官方 DetailsPanel 的 Input/Output 结构。[1] [2]

这不是完整 TerminalBlock details 交付：native body尚无 ANSI spans、copy feedback、16-line head/tail expand、无换行水平 output scroll、home resolution或按 selected call identity重置的内部交互状态。read/diff/search/web selector也仍未实现。因此该增量不改变 T9.6 未完成状态。
