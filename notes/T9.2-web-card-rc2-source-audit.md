# T9.2 Web Card：rc.2 来源审计

**官方基线：** `deepseek-ai/deepseek-harness@b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`（`dsh-v0.1.1-rc.2`）。

> 本文记录 web renderer 的契约；不能替代本提交的 macOS-26编译、XCTest、runtime、paired visual或AX证据。

## Result-side admission

web card是 result-side only。running call没有card；settled result只有 `card:'web'` 且 `kind:'search'` 或 `kind:'fetch'` 才能进入专用body。
generic/unknown card、未知kind或失败路径都必须保留flattened raw generic output。[1]

| kind | 必需数据 | 专用显示 | generic fallback |
|---|---|---|---|
| search | optional answer, sources, truncated | answer + source list + truncation | invalid/unknown result |
| fetch | url, statusCode, truncated | final URL + HTTP status + truncation | invalid/unknown result |
| running | 无result view | 无web card | generic running |

## 安全与primitive行为

来源/最终URL只有 http(s) 时是外部anchor；
`javascript:`、`data:`、`file:`、不可解析URL只显示纯文本。
source label优先非空title，然后有效hostname，最后raw URL；snippet/publishedAt只有非空才显示。search answer使用官方 MarkdownText；
native必须继续用SwiftUI native text/markdown组合，核心界面不得引入WebView。
空search显示 `未找到结果`，truncated search显示 `来源列表已截断`；fetch显示 `HTTP {statusCode}`，truncated显示 `内容已截断`。[2]

## Native尚未实现边界

当前native尚无web adapter、URL安全normalize、search/fetch card、source list或fetch status显示。
下一增量需要Foundation-only strict decode与safe external URL decision，随后以AppKit/SwiftUI链接处理而非WebView接入row/details；
所有未知/malformed payload继续generic fallback。**T9.2保持未勾选。**
