# T5.6：无障碍核心路径的来源映射契约

`official-accessibility-baseline.
json` 的每条核心路径现在必须包含 `source`，并由 `OfficialAccessibilityBaseline.CorePath` 作为必填字段解码。此前 JSON 中虽记录来源，Swift runtime model 却忽略它；
一旦来源字段被误删，标签仍可通过解码和注册表验证，导致 source-to-visual/accessibility review 失去必要的定位信息。

`OfficialUISpecBuildTests` 现在对每条已注册 core path 同时要求：

| 契约 | 运行时检查 |
|---|---|
| 原生来源存在 | `source` 必须是 `Sources/` 下的 `.swift` 路径。 |
| 标签可解析 | 所有 required label 均能解析为锁定 locale catalog 中的值。 |
| 焦点语义存在 | `focusContract` 去除空白后仍非空。 |
| 场景不漂移 | 六个 core scene 唯一，并使用同一 RC8 source commit。 |

这一强化只使现有版本化无障碍基线更难被静默削弱；
它不替代受信任 GUI host 中的真实 AX tree 检查，也不将无头 runner 的系统材质限制放宽为一般性视觉例外。当前代码提交仍须由 macOS-26 执行 baseline/XCTest 与场景相关辅助功能验证后，T5.6 才可关闭。
