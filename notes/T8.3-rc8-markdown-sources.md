1. 在 `GlassUI` 增加无 HTML 执行的 parser/renderer，覆盖 paragraph、inline code、emphasis、strong、list、blockquote、fenced code 与安全外链；语法支持必须只增不猜。

## 原生基础实现（待 macOS-26 CI）

`NativeMarkdownRenderer.swift` 已实现 bounded native document model：先以稳定 id 分割 fenced code，再对 prose 作受限 inline Markdown 解析。`NativeMarkdownSecurityPolicy` 只放行带 host 的绝对 `https`/`http` URL，并删除可执行 HTML tag；`file:`、`javascript:`、`data:`、`mailto:` 与相对 destination 会被降为不可交互的可见文本。原生 code block 使用等宽 `Text`、language banner 与 `NSPasteboard` copy/check 反馈，未加载 HTML、高亮网页或 WebKit。

`NativeConversationNodeRow` 现将 `CoreAssistantNode` text blocks 传给该 renderer，并把 `running` 显式传递给 Markdown view，继续复用 `ConversationNodeReducer` 的 stable key。`NativeMarkdownRendererTests` 覆盖 HTTP(S) 白名单、unsafe URL 拒绝、可执行 HTML/unsafe link 降级、fenced-code 分段，以及未闭合 streaming fence 不重建先前 prose block。当前仅覆盖基础 parser/security；数学、footnote/reference 解析、真实 project-path Host action、代码语法 token 高亮与 official/native screenshot 配对仍待继续实现。T8.3 **未勾选**。

补充：`NativeCodeHighlighter` 已为 Swift、JSON、Bash、TypeScript/JavaScript 与 Python 等常见 fence 以纯原生 token 分类实现关键字、字符串、数字、注释配色；未知 language 完整走 plain fallback。`NativeMarkdownRendererTests` 证明支持语言的 token 分类和包含 `<script>` 文本的未知 language fallback，说明 code fence 仍仅作为文字而非 HTML/脚本处理。此实现待 macOS-26 CI 及 official/native code-block 视觉场景闭环。

## RC8 project-path Host action 基础（待 renderer vocabulary 接入）

RC8 `MarkdownText.tsx` 仅在 **settled** state 接收 owner-provided `MarkdownFileMentions`；`render.tsx` 先识别 absolute HTTP(S) inline-code，再对不在 anchor 内的 inline-code 以 vocabulary `resolve`，未解析 token 保持惰性 code。`ui-conversation/src/client/apply.ts` 将 resolver 绑定到 closing owner，`openFile(path)` 使用 session `cwd` 调用 `resolveWorkspacePath`，最终交给 Host-owned `workspaces.openPath`；失败在 chat row 静默。该链路说明 project-path 绝不是普通 Markdown `file:` URL。

原生 Core 现新增 `HostAPI.openPath` / `NativeHostPathAPI` 与 `NativeProjectPathResolver`，严格镜像 RC8 cwd resolve，并由 `NativeSessionStore.openKnownProjectPath` 仅接收未来 owner vocabulary 已认可的非 URL token；调用通过 verified Host transport 的 `host.openPath({ path })`，UI 不持有本地 file opener。`HostPathAPITests` 使用 URLProtocol replay 断言 verified Host 会发送 typed RPC 并解码 `opened`，diagnostics-only Host 在 carrier 前拒绝；`NativeSessionStoreTests` 覆盖相对 cwd resolve 和 file/HTTP/blank token 不触达 facade。当前 `NativeMarkdownText` 尚未拥有 RC8 owner-provided file vocabulary，因此所有 inline-code 仍保持惰性；此基础**不代表 T8.3 project-path renderer 已完成**。
