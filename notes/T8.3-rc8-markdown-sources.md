## 实现和测试顺序

1. 在 `GlassUI` 增加无 HTML 执行的 parser/renderer，覆盖 paragraph、inline code、emphasis、strong、list、blockquote、fenced code 与安全外链；语法支持必须只增不猜。
2. 让 `NativeConversationNodeRow` 对 `CoreAssistantNode` 的 text block 调用原生 renderer；其 stable node key 继续来自 `ConversationNodeReducer`。
3. 增加 XCTest 攻击 fixture：`javascript:`、`data:`、`file:`、相对 URL、HTML/script tag 与恶意 code fence 都不可造成系统 URL 打开、脚本执行或 untrusted rich-text execution；同时以允许的 HTTPS URL 与 code-copy 测试证明白名单可用。
4. 为普通 code fence 建立 locked RC8 official/native 同状态窗口截图与浅/深色差异分类；T8.3 在安全、行为、视觉和当前 SHA macOS-26 CI 全部闭环前保持未勾选。
