# T6.6：RC8 `turn-max-tokens` 扩展节点来源与原生映射

> **规格锁定。** 本项只依据 `deepseek-ai/deepseek-harness@141eb6fef83422698aef7a981029e843e8161534` 的 `packages/client/ui-conversation/src/client/conversation-nodes/turn-max-tokens.ts`；不以其它版本或 renderer 外观推断 Core 事件合同。

## 官方事件与投影合同

| 官方位置 | RC8 行为 | Glass Core 映射 |
|---|---|---|
| `turn-max-tokens.ts:41-44, 50-54` | 只有 `turn/end` 且 `reason.kind === "max-tokens"` 才匹配；稳定 identity 是 `String(turn)`。 | `TurnMaxTokensDefinition.match` 同时验证事件类型、reason kind 与有效整型 turn；completed/cancelled/error 终止不产生 notice。 |
| `turn-max-tokens.ts:20-24, 65-71` | payload 包含 `turn`、闭合 location 的最后 `step`、事件 `seq` 与 `time`。 | `CoreTurnMaxTokensNode` 投影为 renderer-safe 的四个字段；location 为 turn 时取 `turn.steps.last?.step ?? 0`，缺失位置安全降级为 `0`。 |
| `turn-max-tokens.ts:26-39, 72` | 有 closing assistant/tail 时 notice 使用 synthetic offset 插在 closing assistant 与 turn-tail 之间；**没有 closing assistant 时**使用原始 `turn/end` seq。 | Glass 当前尚未注册 RC8 `turn-tail` renderer/Core node，因而严格采用官方“没有 closing tail 时”的 raw `turn/end` anchor fallback，不伪造 synthetic 偏移或 closing message。 |
| `conversation-nodes/register.ts:10-13, 27-29` | 官方 conversation registry 显式注册 `turn-max-tokens`，位置在 turn error 后、turn tail 前。 | `ConversationCoreNodeRegistry.initialDefinitions()` 在 `TurnErrorDefinition` 后注册 `TurnMaxTokensDefinition`，为后续 T8 renderer 留出稳定 `kind`。 |

## 回归范围

`ConversationCoreNodesTests.testTurnMaxTokensNoticeUsesClosingTurnCoordinatesAndRejectsOtherEndReasons` 验证 max-tokens end event 的 turn/step/seq/time 和 raw anchor，并以 cancelled turn/end 作为负例，防止非上限原因生成伪 notice。
