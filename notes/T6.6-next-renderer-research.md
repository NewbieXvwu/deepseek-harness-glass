## Subagent catalog authority seam

已新增 `DSHAPIClient.subagentList`、`SubagentsAPI.list` 及完整 `SubagentListRequest/Response/EntryDTO`。它严格映射 RC8 `subagent.list({ parentSessionId }) -> { entries, parentAvailable }`，保留 child/diagnostic discriminator所需字段，暂不在 UI中以 summaries伪造 catalog。catalog header action、recursive disclosure、read-only composer、fixture/AX/paired visual仍待实现。

## Subagent catalog session state

`NativeSessionStore` 现持有 optional complete `subagentCatalog`、loading state与 explicit `refreshSubagentCatalog()`。刷新只使用 `NativeSubagentCatalogAPI`，并以 recovery generation和active session fence拒绝旧响应；switch/deinit取消并清空旧 catalog。`NativeShellPresentation.connectVerifiedHost` 将 `apis.subagents` 注入 store。该层尚未渲染 tree或接管 composer。

## Subagent catalog initial header renderer

`NativeSubagentCatalogHeaderAction` 已由 `NativeShellPresentation` 注册为 header actions order 10。它在出现时显式刷新 Host catalog，且仅在 complete catalog提供 child或 diagnostic evidence后显示 28px trigger；popover使用 RC8 336px width展示 direct child mode/activity与 diagnostics。当前不从 summaries推导 rows，也尚未实现递归 branch、child navigation、read-only composer、fixture/AX或 paired visual evidence。

## Subagent direct-child navigation

`NativeConversationContributionContext` 现携带 shell-owned `openSession` closure。首层 catalog healthy child rows以真实 native button调用该 closure，关闭 popover后打开对应 Host session；诊断仍不可操作。此处不生成 child session、未将 ordinary summaries当作 catalog，递归 branch与composer仍待实现。

## Subagent continuable actions

已增加 `SubagentPromptRequest` 与 `SubagentInterruptRequest`，均强制 durable `parentSessionId`、`childSessionId`与 `mode=continuable`，分别映射 RC8 `subagent.prompt` 与 `subagent.interrupt`。prompt receipt只保留 accepted messageId，interrupt receipt只表示 admission；二者均不乐观修改 Host child running/queue state。native child composer与 interrupt controls仍待实现。

## One-shot subagent read-only composer

`NativeSubagentReadOnlyComposer` 已映射 RC8 one-shot read-only title/body，并在 approval/question takeover之后、普通 composer之前，仅当 `extensionState.subagentIdentity` 是有效 `.identity(mode: .oneShot)` 时出现。absent、null sentinel与 malformed descriptor保持普通 composer，避免猜测 read-only；continuable parent-unavailable与typed child input仍待实现。

## Recursive subagent catalog foundation

`NativeSessionStore` 现保存按 parent ID 键控的 complete catalog cache、loading IDs与各 parent task；所有请求沿 selected-root generation fence执行。`NativeSubagentCatalogHeaderAction` 根据 `hasChildren` 展开/折叠，并仅调用 `refreshSubagentCatalog(parentSessionID:)` 后渲染该 parent 的 Host rows，不会从 summaries递归填充。递归菜单的完整 keyboard tree、loading/retry rows、paired visual/AX仍待闭环。

## Continuable subagent route 与 parent-unavailable takeover

RC8 `packages/client/runtime/src/client/sessions/session.ts` 将有效 continuable address 的 prompt/cancel 分别路由到 `subagent.prompt` / `subagent.interrupt`，不以普通 `session.prompt`/`session.cancel` 代替；`ui-subagent/src/client/index.ts` 则在 one-shot 或 parent 不可用时接管 composer 为只读。本地现以 `NativeSessionStore.SubagentRoute` 保留仅由 complete Host catalog child row给出的 `parentSessionID`、`childSessionID`、known mode及 `parentAvailable`。普通 session open 会丢弃不匹配 child 的旧 route，catalog child navigation 会保留匹配 route，因而不从 session summary或 ID 文本推断权限。

有效且 parent available 的 continuable route 只允许通过注入自同一 verified `HarnessAPIs` composition root 的 `SubagentsAPI` 发送 typed `SubagentPromptRequest`；running child 的取消只发送 typed `SubagentInterruptRequest`，即使 parent 当前不可用也不退化为普通 session cancel。one-shot、diagnostic、未知 mode或缺 continuation facade均 fail closed；`parentAvailable=false` 在 view层显示官方 read-only composer，阻止输入提交。`NativeSessionStoreTests.testContinuableSubagentRouteUsesParentChildPromptAndInterrupt` 锁定完整 parent-child request和普通 session facade零调用；`testSubagentRouteAcceptsOnlyCatalogChildWithKnownMode` 锁定 route筛选。仍须完成 composer互动视觉/AX、catalog loading/retry rows和 macOS-26 权威测试/official-native配对，故 T6.6 不勾选。
