## 当前平台修复

macOS-26 run `32386749181` 首次编译 Goal dock 时显示 Swift 不允许从 `defer` 的 `guard ... else { return }` 转移控制流。`NativeSessionStore` 的 Queue 与 Goal action fences 已改为同条件 `if` 清理：只有非 cancelled、仍为相同 active session 且（Queue）仍为相同 busy item 时清除 submitting state。该修复不改变 Host request、CAS/row identity，亦不改变任何 visible projection。

macOS-26 run `32388160153` 随后显示 Goal 两处和 Queue 一处 failure text 误引了不存在的 `OfficialUISpec.Typography.xxxs12`。三处均已改为已登记的 12pt `xxs12` token；这是编译时命名修复，不改变任何 failure文案、action fence、Host projection 或几何参数。macOS-26 run `32389276146` 接着显示 Queue `failureText` 的 switch expression 缺少显式 `return`；已以 `return switch` 恢复 Swift 控制流，同样不改变 action-specific locale mapping。

## Snapshot 采集基础

`NativeSessionStore.loadSnapshotQueueFixture()` 只注入两个 `placement=queued` 的 Host-shaped rows（一个 text、一个无 `text` 的 image content）并保留 running state；`SnapshotExporter` 的 `DSH_GLASS_SNAPSHOT_MODE=queue` 将其装配进既有 conversation window。该 fixture 用于后续针对非 text edit-disabled affordance和多行收起的 official/native light/dark 成对采集；它不安装 Queue API、不会提交 RPC，也不代表已经完成视觉或无障碍验收。

## 待闭环证据

Queue renderer、Goal renderer以及本次 action transport尚缺真实 Host `session/queue` capture、official/native light/dark paired PNG、AX keyboard/focus tree、failure visual classification与当前 SHA macOS-26 XCTest。Linux 不能构建共享 SwiftPM GUI target（既有 AppKit/SwiftUI 边界），因此本地仅运行 syntax、asset regeneration、RC8 matrix/visual/workflow/document gates；macOS CI 是类型和 GUI runtime 权威。
