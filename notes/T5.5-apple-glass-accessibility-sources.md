# T5.5 Apple API source notes

Apple 的 [Applying Liquid Glass to custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views) 说明，`GlassEffectContainer` 会组合自定义 Liquid Glass 形状、改善渲染性能，并允许在视图层级转换中进行有目的的形变。该文档还明确建议限制同时出现的效果，并在需要协调形状时以共享 `Namespace` 的 `glassEffectID(_:in:)` 标识它们。Apple 的 [GlassEffectContainer](https://developer.apple.com/documentation/swiftui/glasseffectcontainer) API 文档确认，该类型在 macOS 26 及以上可用，并以可选间距及内容闭包初始化。

Apple 的 [accessibilityReduceTransparency](https://developer.apple.com/documentation/swiftui/environmentvalues/accessibilityreducetransparency) 文档定义了读取系统“降低透明度”偏好的环境值；SwiftUI 的 `colorSchemeContrast` 表示标准或增强对比度，`accessibilityReduceMotion` 则表示“减少动态效果”偏好。因此，原生实现只对已有且互斥的 sidebar 打开/收起导航操作使用一个 `GlassEffectContainer` 和共享 `glassEffectID`，并在相应辅助功能环境下关闭自定义玻璃或动画。系统 sidebar/inspector 材质仍完全由 AppKit 负责。

Apple 的 [NSAccessibility `accessibilityChildren()`](https://developer.apple.com/documentation/appkit/nsaccessibilityprotocol/accessibilitychildren()) 文档说明，该协议方法返回辅助功能层级中的子元素。T5.6 后续运行时测试将以 `NSHostingView` 装载原生核心路径，再递归读取此层级以确认真实导出的 VoiceOver 名称与可焦点控件，而不是只依赖静态源码检查。
