## Jobs 同状态基线差异

macOS-26 [run 32336004226](https://github.com/NewbieXvwu/deepseek-harness-glass/actions/runs/32336004226) 的 `jobs-expanded-light` official/native pair 显示，当前 native 顶部只有 56px 简化 `Chat` 标题行，缺少官方的 session title（`Reply with the single word…`）、agent preset、header action seat、session-log utility、35px `Chat / Trajectory` tab strip 和 2px active blue bar。原生 transcript 也只呈现 user/assistant 文本，而官方 fixture 含 Context injection、Think、copy/feedback row 与 turn failed node；composer 同样仍为简化卡。这些是实际差异，不能由 Jobs popover 的正确 locale 或 T7 sidebar 对齐抵消。

当前 `NativeWorkspaceStore.loadSnapshotFixtureWorkspace()` 已提供 Host-shaped selected `fx-alpha` summary（title `Fixture 历史会话`），而 official jobs capture 使用隔离 fixture 自身的 `Reply with the single word…` title。T8.1 不得伪造或硬编码 latter；应先以 Host summary `displayTitle` 为唯一 production/snapshot header truth，并在后续 snapshot-contract work 中将 native/official fixture title source 统一。`NativeSessionStore` 已保证 resident session restore preserves draft/items across switch，header/tab state must not invalidate that guarantee.

## 已核验的补充来源

RC8 `packages/client/ui-jobs/src/client/index.ts:28-39` 明确把 Jobs 以 `id='job-list'`、`order=20` 注册至 `conversation.session.header.actions`；`NativeJobsHeaderAction` 必须因此处于 title-adjacent action row，而不是 right-side utility。`packages/client/ui-agent-preset/src/client/AgentPresetLabel.tsx:42-63` 仅在 session summary 的 `agentPreset` 存在时显示只读 label；其 `locales.ts:169-191` 为 system `standard` 映射 `presetStandardName`（en 为 `Standard mode`），未知 roster item 回退 id。T8.1 的本轮 native jobs fixture 因而将 captured Host summary 投影为 `agentPreset='standard'`，但生产路径仍直接读取 Host `SessionSummaryDTO.agentPreset`。

官方 [jobs capture script](https://github.com/NewbieXvwu/deepseek-harness-glass/blob/main/tools/reference-capture/capture-official-welcome.e2e.ts) 的 `recordedPrompt`（第 11 行）创建 session；`32336004226` 的 locked `jobs-expanded-light.json` 记录 `geometry.title = "Reply with the single word — DSH Local Build"`，同一 ARIA/text snapshot 记录 session durable label `Reply with the single word`、`Standard mode`、`Chat` 和 `Trajectory`。RC8 [DocumentTitle.tsx](https://github.com/deepseek-ai/deepseek-harness/blob/141eb6fef83422698aef7a981029e843e8161534/packages/client/ui-renderer/src/client/DocumentTitle.tsx) 第 17–22 行规定 selected durable title 使用 `${title} — DSH Local Build`，无 selection 则恢复 `DSH Local Build`；原生 shell 的隐藏 AppKit titlebar 同样必须维持这个 document state。

RC8 [ui-trajectory registration](https://github.com/deepseek-ai/deepseek-harness/blob/141eb6fef83422698aef7a981029e843e8161534/packages/client/ui-trajectory/src/client/index.ts) 第 43–64 行以 `id='trajectory'`、`order=10` 注册第二个 view tab。当前 native 尚未具备 T9.5 的真实 trajectory target renderer，故 T8.1 当前 registry 只注册可渲染的 `chat`；它已实现 unknown retained id→Chat fallback 和 per-resident-session view id 保持，但**不得**把尚无 renderer 的 Trajectory tab 伪装为可用。与官方 jobs screenshot 的 Trajectory tab 差异继续明确归属 T9.5/T8.1 的后续插件 view 接入，不能在本轮视为完成。
