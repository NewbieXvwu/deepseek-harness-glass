## 实现约束

1. `ConversationNodeReducer` 只消化严格升序的 `SessionEventDTO` history/live window；扩展暂态不得伪装成 durable event。
2. 由 mux 或 projection 驱动的状态必须以 session ID、subscription generation 和 sequence fence 隔离；Host restart 后只能由新 authority baseline 恢复。
3. 每个 durable definition 必须有 start、update、最终完成、取消/closed-boundary interruption、坏 payload 与 window-cut 负例；每个 mux/projection adapter 必须有 foreign session、malformed payload、whole-snapshot replacement 与 reconnect clearing 负例。
4. 未注册的第三方扩展只可显示安全的 typed unsupported/fallback 记录，或保持隐藏；不得把原始 payload、secret、unknown action JSON 或推断性文案传入 SwiftUI。
5. T6.6 只有在所有状态投影拥有 Core fixture、目标 renderer snapshot、取消/错误覆盖，且插件缺失降级经过运行态验证后才能勾选。
