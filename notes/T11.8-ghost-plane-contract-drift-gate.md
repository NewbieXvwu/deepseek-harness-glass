# T11.8：Ghost Plane 骨架契约防漂移门禁

**状态：** 已建立锁定上游 source → JSON fixture → native/runtime validator → CI 的可证伪链路；保持未勾选，直至当前提交取得自身 macOS-26 成功证据，
并在后续 GP-2 host 中验证完整 service injection lifecycle。


## 1. 生成边界

`tools/spec-generation/generate_ghost_plane_contract.
py` 只读取锁定官方 DeepSeek Harness 的六个生产 source：conversation SlotMap、ConversationRoot、ChatView、ChatNodeSeat、AssistantMarkdown 与 modules manifest。
它输出版本化 `official-ghost-plane-contract.
json`，包含 source commit、每份 source 的 SHA-256、结构 selector、SlotMap entry（name/kind/scope）以及 `__DSH_BOOT__` / `__ModuleLoader__.
load` / `client.js?rev` wire metadata。

该生成器不读取本项目 `.swift` 文件，避免以源码关键词证明安全或行为。上游 SlotMap、DOM 或 ModuleLoader 的任何变动都会导致重新生成结果与受审 fixture 不同，必须经显式升级审查。

| 契约类别 | 来源 | 当前 gate 断言 |
|---|---|---|
| Scroll / flow / composer anchors | 官方 `ConversationRoot`、`ChatView` |
`[data-conversation-scroll]`、`[data-chat-flow]`、`[data-composer-seat]`。
|
| 稳定 chat row 生命周期 | 官方 `ChatNodeSeat`、`AssistantMarkdown` | anchor key、flow key/kind、streaming 和 phase 属性。 |
| Conversation SlotMap | 官方 `contract/slots.ts` | session/header/node/turn tail/details/composer 与完整 slot list 的 kind/scope。 |
| Module loader wire | 官方 `modules/manifest.ts` | boot global、registration facade/method、plugin client bundle template、factory model。 |

## 2. 本地骨架与运行态对齐

`OfficialGhostPlaneContract` 从 Core resource 读取 fixture，校验 schema、锁定 source commit、source digest 格式和 ModuleLoader wire；
`validateSkeletonSelectors` 将生产 `GhostPlaneSkeleton.
requiredSelectors` 与 fixture 做双向集合比较。
漏掉官方 selector 或增加未审阅 selector 都返回 typed `skeletonSelectorDrift`。这不是 source-text gate：比较的是已生成的官方结构化合同和运行中可调用的 Core declaration。

GP-1 skeleton 已显式输出 `data-phase` 和 `data-chat-flow-kind`，使其 selector inventory 与官方 fixture 对等；其 HTML 仍保持内容为空。
最终 WKWebView/SlotRegistry 的真实运行态加载、bridge service declaration 与 injection success 仍由 GP-2 / T11.5 负责，不能以本 fixture gate 宣称完成。

## 3. CI 与负例

`check-official-ghost-plane-contract.py` 在 native-ui 的 locked official checkout 后重生成并精确比较 fixture。
`test-official-ghost-plane-contract.
py` 证明两种负例都会失败：本地 fixture 删除 required selector，或上游 SlotMap 中移除 `conversation.chat.turnTail`。自测仅复制六个契约 input 文件，不复制官方 node_modules。

`OfficialGhostPlaneContractTests` 覆盖 resource metadata、ModuleLoader wire、完整 skeleton selector 正例和双向 selector drift 负例。
`official-ghost-plane-contract-portable-check.swift` 还在 Linux Swift 6.2.4 中编译生产 validator 与 skeleton，已接入 `portable-checks`。
