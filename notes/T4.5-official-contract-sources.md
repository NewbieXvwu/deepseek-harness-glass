# T4.5 官方 contract 来源摘要

- 锁定官方基线：`deepseek-ai/deepseek-harness@99f6f02fecdb7dff40c3fbc9470f5907c29f74ca`。
- `packages/host/apiproxy/src/api/index.ts:21-41` 是根 contract：`sessions`、`subagents`、`host`、`workspace`、`skills`、`agentPresets`、`events`、`goals`、`settings`、`credentials`、`llm` 与 host-only `downloads`；`respond` 是非域方法的 ClientResponse entry。
- `packages/host/apiproxy/src/api/rpc-map.ts:24-77` 列出所有 client-request wire paths。Goals wire paths (`goal.create/edit/pause/resume/complete/clear`) 在 Swift 命名为 `CommandsAPI`，但不可改变实际 wire method。
- `credentials.schema.ts:23-48`：describe `{refs}` -> `{credentials: Record<ref,{configured,source?,writable}>}`；set `{ref,value}`、unset `{ref}` 都返回空 object。
- `llm.schema.ts:22-64`：providers/models 为空 request；discoverModels `{settingsNs,provider?,baseURL?,api?,apiKey?}`，apiKey 是 write-only 敏感输入，日志/trace 不得记录 payload。
- `skills.schema.ts:20-28`：skill.list `{sessionId}` -> skills rows `{name,description,whenToUse?,modelInvocable}`。
- `agent-presets.schema.ts:22-88`：list/select/read/copy/openDocument/remove 的 typed DTO shapes；openDocument wire value 可为 `{opened:true}` 或 `{opened:false,path}`。
- `goals.schema.ts:20-79`：goal mutations；所有非 clear 返回 `{ref:{id,revision}}`，clear 返回 `{cleared:true}`；当前 goal state 属于 session projection。
- `downloads.ts` 是 host-only GET、无 RPC envelope：sessionLog `{sessionId,includeDescendants?}`。
- SSE 依据：`fetch/client.ts:352-408`（mux/host endpoint、onOpen、blank-line frame、bad frame drop、reader cancel）与 `events.schema.ts:42-93`（mux session/event.seq、session/projection.seq 与 host frames）。
- Feature migration inventory：`NativeSplitContainer`、`NativeWorkspaceStore`、`NativeSettingsStore`、`NativeSessionStore` 先前直接持有 `DSHAPIClient`；T4.5 必须改为 `HarnessAPIs` 的 domain facades，Feature/UI 不构造 URL、wire envelope 或 JSON dictionary。
